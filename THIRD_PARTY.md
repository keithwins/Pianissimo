Pianissimo's own code is MIT licensed (see LICENSE). This file lists everything else that ships with it.

## Starter scores

The "Add starter pieces" button installs the scores below. The compositions are all in the public domain.

| Piece | Encoding |
|---|---|
| Minuet in G major, BWV Anh. 114 | Mutopia Project (Bach-Gesellschaft edition), public domain |
| Musette in D major, BWV Anh. 126 | Mutopia Project (Bach-Gesellschaft edition), public domain |
| Prelude in C major, BWV 846 | Notes only, encoded for Pianissimo, CC0 1.0 |
| Waltz in D-flat major, Op. 64 No. 1 | Notes only, encoded for Pianissimo, CC0 1.0 |
| Maple Leaf Rag (Joplin) | Notes only, encoded for Pianissimo, CC0 1.0 |
| The Entertainer (Joplin) | Notes only, encoded for Pianissimo, CC0 1.0 |

"Notes only" means pitches, rhythms, ties, clefs, key, meter and tempo. Slurs, dynamics, articulations, fingerings and layout from any published or user-uploaded edition were removed, so no editor's markings are redistributed. Fingering you see in these pieces is suggested by Pianissimo or entered by you.

Scores you add yourself stay in your own music folder and are your responsibility.

## Ideas and research

Fingering suggestions use a cost model in the spirit of Parncutt et al. (1997) and Jacobs (2001). No code from those papers is included.
